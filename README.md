# T05 대화가 끊겨도 이어지는 프로젝트 — 작업 저장소

## 고칠 것 (기능 1개)

짤·카드 스튜디오(T03)의 **템플릿 JSON 가져오기 값 검사**.

지금은 필수 항목이 "있는지"만 보고 값이 맞는지는 보지 않는다. 그래서 `"ratio": "3:2"`, `"color": "red"`, `"size": "크게"` 같은 값도 그대로 저장된다.
값이 잘못된 템플릿이 하나라도 있으면 **아무것도 저장하지 않고**, 몇 번째 템플릿의 어떤 항목이 틀렸는지 안내하게 바꾼다.

- 시작 코드: T03 제출본 `dochiHS/card-studio` 커밋 `3331158bb861a4b654a9683867fb43cf65d3d221`의 `index.html`
- 바꾸는 파일: `index.html` 하나

## 고정 검사 10개 (작업 시작 전에 고정, 이후 변경 금지)

`tests.html`에 들어 있다. 검사 삭제·완화·기대값 변경은 하지 않는다.

| ID | 입력 | 기대값 |
|---|---|---|
| T05-01 | 정상 템플릿 3개 | 성공 안내 "가져왔습니다" · 템플릿 1개 → 4개 |
| T05-02 | 문법이 깨진 JSON | 오류 "문법이 손상된 JSON" · 기존 1개 그대로 |
| T05-03 | 2번째 템플릿에 color 없음 | 오류에 "2번째 템플릿"·"color" · 기존 1개 그대로 |
| T05-04 | ratio "3:2" | 오류에 "1번째 템플릿"·"ratio" · 기존 1개 그대로 |
| T05-05 | color "red" | 오류에 "1번째 템플릿"·"color" · 기존 1개 그대로 |
| T05-06 | size "크게" | 오류에 "1번째 템플릿"·"size" · 기존 1개 그대로 |
| T05-07 | text 123(숫자) | 오류에 "1번째 템플릿"·"text" · 기존 1개 그대로 |
| T05-08 | align "middle" | 오류에 "1번째 템플릿"·"align" · 기존 1개 그대로 |
| T05-09 | size 20·160 (경계값) | 성공 "가져왔습니다" · 1개 → 3개 |
| T05-10 | 3개 중 3번째만 size 161 | 오류에 "3번째 템플릿"·"size" · 1·2번째도 저장 안 됨 |

오류 안내 예: `가져오지 못했습니다. / 1번째 템플릿의 "ratio" 값이 올바르지 않습니다 / 기존 템플릿 1개는 그대로 있습니다.`
(따옴표로 감싼 항목 이름이 안내에 들어가야 한다. 마지막 줄은 기존 코드가 이미 붙인다.)

올바른 값의 기준 (편집기 조작판과 같음):
ratio = `1:1`·`4:5`·`9:16` / text = 문자열 / size = 숫자 20~160 / color = `#RRGGBB` / align = `left`·`center`·`right`

## 실행 방법

`tests.html`은 같은 폴더의 `index.html`을 안에 띄워 검사하므로, **파일을 더블클릭하면 동작하지 않는다**(브라우저 보안). 아래 둘 중 하나로 연다.

1. 이 폴더에서 `py -m http.server 8000` (또는 `python -m http.server 8000`) 실행 → 브라우저로 `http://127.0.0.1:8000/tests.html` → **검사 실행**
2. GitHub Pages에 올린 뒤 `https://dochihs.github.io/t05-relay/tests.html` → **검사 실행**

결과 맨 위에 `N / 10 PASS`, 그 아래에 기록용 한 줄(`T05-SUITE-v1 | 시각 | N/10 PASS | FAIL: …`)이 나온다.
시작 상태에서는 **4 / 10 PASS**(T05-01·02·03·09 통과)다.
